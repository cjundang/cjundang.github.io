**Requirement Specification: เกม Hangman คำศัพท์เครือข่ายคอมพิวเตอร์**

โปรแกรมเป็นเว็บแอปพลิเคชันแบบ Single Page Application (SPA) สำหรับฝึกคำศัพท์เครือข่ายคอมพิวเตอร์ โดยอ่านคำศัพท์และความหมายจากไฟล์ `data.md` สุ่มคำให้ผู้เล่นทาย และแสดงคะแนนพร้อมสถิติเวลาการเล่น

**1. ข้อมูลคำศัพท์**

ไฟล์ `data.md` ต้องจัดเก็บคำศัพท์ภาษาอังกฤษและความหมายภาษาไทย โดยใช้รูปแบบตารางดังนี้

```markdown
| Word | Meaning |
|---|---|
| ROUTER | อุปกรณ์ส่งต่อแพ็กเก็ตระหว่างเครือข่าย |
| SWITCH | อุปกรณ์เชื่อมต่อภายในเครือข่าย LAN โดยส่งต่อเฟรมตาม MAC Address |
| PROTOCOL | กฎหรือข้อตกลงในการสื่อสารข้อมูล |
```

ระบบต้องตรวจสอบข้อมูลก่อนเริ่มเกม โดยไม่ใช้รายการที่ไม่มีคำศัพท์ ไม่มีความหมาย หรือมีคำศัพท์ซ้ำกัน ทั้งนี้ ให้ถือว่าตัวพิมพ์ใหญ่และตัวพิมพ์เล็กเป็นคำเดียวกัน

**2. ข้อกำหนดการทำงาน**

| รหัส | ข้อกำหนด |
|---|---|
| FR-01 | ระบบต้องรับชื่อผู้เล่นก่อนเริ่มเกม และไม่อนุญาตให้ใช้ชื่อว่าง |
| FR-02 | ระบบต้องอ่านคำศัพท์และความหมายจากไฟล์ `data.md` |
| FR-03 | ระบบต้องสุ่มแสดงคำศัพท์ครั้งละ 1 คำ โดยไม่ซ้ำภายในรอบการเล่นเดียวกัน |
| FR-04 | ระบบต้องแสดงความหมายของคำเป็นคำใบ้ และซ่อนคำตอบด้วยช่องว่างตามจำนวนตัวอักษร |
| FR-05 | ผู้เล่นต้องทายตัวอักษรภาษาอังกฤษได้ครั้งละ 1 ตัว โดยไม่แยกตัวพิมพ์ใหญ่และตัวพิมพ์เล็ก |
| FR-06 | เมื่อทายตัวอักษรถูก ระบบต้องเปิดเผยตัวอักษรนั้นทุกตำแหน่งในคำ |
| FR-07 | ระบบต้องกำหนดจำนวนครั้งที่ทายได้เท่ากับ 50% ของความยาวคำ โดยปัดเศษลง |
| FR-08 | หากผู้เล่นเปิดเผยตัวอักษรครบทั้งคำภายในจำนวนครั้งที่กำหนด ต้องได้รับ 1 คะแนน |
| FR-09 | หากใช้จำนวนครั้งครบแล้วยังทายคำไม่สำเร็จ ต้องได้รับ 0 คะแนน และระบบต้องแสดงคำเฉลย |
| FR-10 | ระบบต้องจับเวลาแยกสำหรับแต่ละคำ ตั้งแต่แสดงคำใบ้จนสิ้นสุดการทายคำนั้น |
| FR-11 | เมื่อจบแต่ละคำ ระบบต้องแสดงคำตอบ คะแนน และเวลาที่ใช้ พร้อมปุ่มไปยังคำถัดไป |
| FR-12 | ระบบต้องแสดงชื่อผู้เล่น จำนวนคำที่ทายถูกต่อจำนวนคำที่เล่นจบ และเวลาเฉลี่ยต่อคำ |
| FR-13 | เมื่อเล่นครบทุกคำ ระบบต้องแสดงผลสรุปและอนุญาตให้เริ่มรอบใหม่ได้ |

**3. กติกาการนับจำนวนครั้ง**

ในข้อกำหนดฉบับนี้ **การทายตัวอักษรใหม่แต่ละครั้งนับเป็น 1 ครั้ง ทั้งกรณีทายถูกและทายผิด** การทายตัวอักษรเดิมซ้ำหรือกรอกข้อมูลไม่ถูกต้องไม่นับเป็นครั้ง และไม่เปลี่ยนสถานะเกม

จำนวนครั้งที่ทายได้คำนวณจาก

\[
G = \left\lfloor \frac{L}{2} \right\rfloor
\]

โดย \(L\) คือจำนวนตัวอักษรในคำ และ \(G\) คือจำนวนครั้งสูงสุดที่ทายได้ กำหนดให้คำศัพท์มีความยาวอย่างน้อย 2 ตัวอักษร

| ความยาวคำ | จำนวนครั้งที่ทายได้ |
|---:|---:|
| 3 ตัวอักษร | 1 ครั้ง |
| 6 ตัวอักษร | 3 ครั้ง |
| 9 ตัวอักษร | 4 ครั้ง |
| 10 ตัวอักษร | 5 ครั้ง |

หากการทายครั้งสุดท้ายทำให้เปิดเผยคำครบ ต้องถือว่า **ทายสำเร็จและได้รับ 1 คะแนน** ก่อนตรวจเงื่อนไขหมดจำนวนครั้ง

**ข้อสังเกตของกติกา:** คำที่มีจำนวนตัวอักษรไม่ซ้ำมากกว่าจำนวนครั้งที่อนุญาตจะไม่สามารถทายสำเร็จได้ แม้ทายถูกทุกครั้ง เช่น `ROUTER` มีตัวอักษรไม่ซ้ำ 6 ตัว แต่ทายได้เพียง 3 ครั้ง หากต้องการให้ทุกคำมีโอกาสทายสำเร็จ ควรเปลี่ยนเป็นจำกัดเฉพาะ **จำนวนครั้งที่ทายผิด** เท่ากับ 50% ของความยาวคำ

**4. การจับเวลาและสถิติ**

- เริ่มจับเวลาเมื่อคำใบ้และช่องคำศัพท์แสดงพร้อมให้เล่น
- หยุดจับเวลาเมื่อทายสำเร็จหรือใช้จำนวนครั้งครบ
- ไม่นับเวลาที่ผู้เล่นอ่านเฉลยหรือรอกดคำถัดไป
- เวลาเฉลี่ยต้องรวมทั้งคำที่ทายสำเร็จและไม่สำเร็จ โดยนับเฉพาะคำที่เล่นจบแล้ว
- ก่อนมีคำที่เล่นจบ ให้แสดงเวลาเฉลี่ยเป็น `—`

\[
\text{เวลาเฉลี่ยต่อคำ}
=
\frac{\text{เวลารวมของคำที่เล่นจบทั้งหมด}}{\text{จำนวนคำที่เล่นจบทั้งหมด}}
\]

ตัวอย่างผลสรุป:

```text
ผู้เล่น: CJ
ทายถูก / เล่นจบทั้งหมด: 7 / 10 คำ
คะแนนรวม: 7 คะแนน
เวลาเฉลี่ยต่อคำ: 12.45 วินาที
```

**5. หน้าจอของระบบ**

| หน้าจอ | องค์ประกอบหลัก |
|---|---|
| เริ่มเกม | ช่องชื่อผู้เล่น ปุ่มเริ่มเกม และคำอธิบายกติกา |
| เล่นเกม | ชื่อผู้เล่น คำใบ้ ช่องตัวอักษร ปุ่ม A–Z ตัวอักษรที่ทายแล้ว จำนวนครั้งคงเหลือ เวลา และสถิติปัจจุบัน |
| ผลลัพธ์รายคำ | คำเฉลย ผลสำเร็จหรือไม่สำเร็จ คะแนน เวลาที่ใช้ และปุ่มคำถัดไป |
| สรุปผล | ชื่อผู้เล่น คะแนนรวม จำนวนคำที่ทายถูกต่อคำที่เล่นจบ เวลาเฉลี่ย และปุ่มเริ่มรอบใหม่ |

**6. ข้อกำหนดด้านคุณภาพ**

ระบบต้องรองรับคอมพิวเตอร์และโทรศัพท์มือถือ ใช้งานได้ผ่านปุ่มบนหน้าจอและแป้นพิมพ์ และเปลี่ยนสถานะเกมโดยไม่โหลดหน้าใหม่ หากอ่านไฟล์ `data.md` ไม่สำเร็จหรือไม่มีคำศัพท์ที่ใช้งานได้ ต้องแสดงข้อความแจ้งปัญหาและไม่เริ่มเกม

**7. เกณฑ์ตรวจรับหลัก**

| กรณีทดสอบ | ผลลัพธ์ที่คาดหวัง |
|---|---|
| ไม่กรอกชื่อผู้เล่น | เริ่มเกมไม่ได้ และแสดงข้อความให้กรอกชื่อ |
| สุ่มคำต่อเนื่องจนหมดข้อมูล | ไม่พบคำซ้ำภายในรอบเดียวกัน |
| คำยาว 10 ตัวอักษร | ทายตัวอักษรใหม่ได้สูงสุด 5 ครั้ง |
| ทายตัวอักษรเดิมซ้ำ | จำนวนครั้งคงเหลือไม่ลดลง |
| ทายตัวอักษรที่ปรากฏหลายตำแหน่ง | เปิดเผยทุกตำแหน่ง และนับเป็น 1 ครั้ง |
| ทายคำครบในการทายครั้งสุดท้าย | ได้รับ 1 คะแนน |
| ใช้จำนวนครั้งครบแต่คำยังไม่ครบ | ได้รับ 0 คะแนน แสดงเฉลย และหยุดเวลา |
| เล่นจบ 2 คำ ใช้เวลา 10 และ 20 วินาที | แสดงเวลาเฉลี่ย 15.00 วินาที |
| อยู่ระหว่างเล่นคำถัดไป | คำนั้นยังไม่รวมในจำนวนคำที่เล่นจบและเวลาเฉลี่ย |
